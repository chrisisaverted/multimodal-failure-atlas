# Research and product backlog

## Required before a scored public leaderboard

- Human baseline and response-time protocol
- Private balanced seed schedules per generator
- A second renderer for every scored family
- Dated conformance fixtures for each paid provider adapter
- Declared per-family minimum sample sizes and public aggregation policy
- Native-video versus standardized-frame batch protocol
- Manual review queue for non-deterministically scorable outputs
- Red-team review for answer leakage

- OCR scale, rotation, blur, and temporal persistence
- Visible spatial relations with occlusion controls
- Cross-region chart and diagram integration
- Contrastive feature-collapse pairs
- Long-video evidence placement and distractor density
- Motion direction and speed disentanglement
- State-transition memory after long delays
- Causality versus temporal correlation
- Arrow-of-time reversal
- Audiovisual synchronization and contradiction
- Misleading-language belief reversal
- Linked-question consistency
