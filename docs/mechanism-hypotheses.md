# Mechanism hypotheses and decisive experiments

The atlas currently establishes route-specific behavioral failures. It does not establish that a proprietary route uses a particular frame sampler, patch size, token-pruning policy, or reasoning representation. The map below separates a plausible explanation from the intervention that could earn a causal claim.

| Behavioral signature                                                                   | Families that expose it                                                        | Plausible bottlenecks                                                                                               | Decisive experiment on an open model                                                                                                                                                             |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Exact answers collapse as locally readable evidence becomes spatially distributed      | crossing count, symmetry, XOR, graph degree, parity, maze                      | visual-token budget; spatial merging; static evidence selection; failure to aggregate a global sufficient statistic | hold weights and prompt fixed; sweep native resolution, merge ratio, and token budget; then inject oracle-selected visual tokens and compare with a textualized sufficient statistic             |
| A trace is locally visible, but following identity through crossings fails             | crossing count, sequential swaps, pair collisions                              | correspondence binding; identity overwrite; attention diffusion; task-state loss                                    | probe identity at each layer/event; intervene by tagging identities, revealing one segment at a time, or supplying the exact permutation after each event                                        |
| Individually simple events are recognized but an exact running state is wrong          | route turns, signed accumulator, conservation ledger, temporal set cardinality | insufficient temporal state representation; weak recurrent update; approximate rather than exact aggregation        | freeze the encoded event stream; compare direct decoding, text event transcription, an external symbolic accumulator, and activation patching at each update boundary                            |
| Brief or alternating events disappear under native video but recover when externalized | selective flash, transition count, zone entry                                  | frame selection; temporal patching; motion compression; state update after acquisition                              | render phase-shifted copies at fixed semantics; exhaustively sweep sampling phase/FPS and temporal patch factor; test whether the critical event is linearly decodable before the language model |

## A minimum causal ladder

1. **Behavioral replication:** fresh seeds, balanced answers, substantive denominators, multiple routes.
2. **Input intervention:** vary acquisition parameters while preserving the latent answer.
3. **Sufficient-statistic substitution:** replace visual evidence with the exact event or relation stream. Recovery places the failure before or at construction of that statistic.
4. **Representation test:** show that the required variable is or is not decodable at specified layers and time points.
5. **Activation intervention:** patch or steer that variable and recover the final answer without changing the prompt or answer distribution.
6. **Mechanistic generalization:** predict a new failure surface before measuring it, then confirm it on a frozen generator family.

Only steps 4–6 justify claims about an internal representation. Closed-route preprocessing disclosures can motivate an experiment, but cannot substitute for it.

## High-value next experiment

Use the open Qwen3-VL and Kimi K3 releases to run a matched `native → denser frames → no temporal merge → oracle critical frames → textualized event stream → symbolic state tool` ladder on selective flash, route-turn integration, and signed accumulation. These three families distinguish acquisition, event extraction, state retention, and exact computation more cleanly than a single end-to-end score. Preregister the intervention order and analyze the first stage that restores accuracy.

The prediction is deliberately falsifiable: if native hidden states already decode every event and the exact state at each step, yet the answer remains wrong, acquisition and memory accounts weaken; if denser/no-merge input alone restores performance, a text-only reasoning explanation weakens. If only the symbolic state tool restores performance, the problem is better described as exact state update/computation than visual perception.
