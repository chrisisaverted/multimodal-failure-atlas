## Scientific limits retained on purpose

- No genuine frontier-model scores are published yet.
- Public reference media are educational specimens, not private leaderboard samples.
- Fresh pixels are not claimed to guarantee distributional novelty.
- “Easy for humans” remains a hypothesis until a preregistered human baseline is collected.
- Closed-model mechanism explanations remain hypotheses unless causal evidence exists.
- Provider capability documentation is not treated as measured model capability.
